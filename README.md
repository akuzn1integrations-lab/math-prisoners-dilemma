# Дилемма заключённого — экспериментальный стенд

Репозиторий организован по независимым этапам исследований.

## Step001.Basic — однократная игра без памяти

Первый эксперимент: 21 стратегия с вероятностью предательства от 0% до 100% с шагом 5%. Каждая из 210 различных пар проводит 10 000 независимых однократных игр. Выигрывает стратегия с максимальной суммой собственных очков.

- [Описание эксперимента](Step001.Basic/README.md)
- [Результаты и выводы](Step001.Basic/RESULTS.md)

Запуск при установленном .NET 10 SDK:

```bash
dotnet run --project Step001.Basic/Step001.Basic.csproj
```

Приложение заново создаёт `Step001.Basic/RESULTS.md` с воспроизводимыми результатами (фиксированное зерно генератора случайных чисел).
