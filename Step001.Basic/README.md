# Step001.Basic: однократная дилемма заключённого

Простейшее консольное приложение на C# (.NET 8) для воспроизводимого исследования стратегий без памяти.

## Правила

- Действия: **C** (сотрудничество) и **D** (предательство).
- Классические выплаты: `C/C → (3, 3)`, `D/C → (5, 0)`, `C/D → (0, 5)`, `D/D → (1, 1)`; первая цифра — очки первого игрока.
- 21 неизменяемая стратегия `P00`, `P05`, ..., `P100` предаёт с указанной вероятностью в процентах. Каждое решение — новое случайное испытание без истории, знания решения соперника или адаптации.
- Каждая **неупорядоченная пара различных** стратегий играет 10 000 **независимых однократных** игр (не последовательную повторяющуюся дилемму). Самоигры не проводятся.
- Всего: 210 пар, 2 100 000 игр, по 200 000 игр на стратегию. В каждой игре очки начисляются обоим участникам.
- Победитель — максимальная **сумма индивидуальных очков** по всем встречам, а не наибольшая сумма очков всей группы.

## Запуск

Требуется .NET 8 SDK. Из корня репозитория:

```bash
dotnet run --project Step001.Basic/Step001.Basic.csproj
```

Приложение выводит победителя и путь к отчёту, а также перезаписывает `Step001.Basic/RESULTS.md` таблицей результатов.

Генератор `SplitMix64`, начальное зерно `20261118`. Для каждой пары создаётся отдельный детерминированный поток с зерном, зависящим от двух вероятностей; генератор не зависит от платформенной реализации `System.Random`. Благодаря этому повторный запуск с тем же кодом и настройками создаёт одинаковую таблицу. Независимость означает отсутствие переноса состояния игрока или игры между испытаниями; случайные выборы моделируются псевдослучайным генератором.

## Как интерпретировать

Если доля предательства игрока равна `p`, а соперника — `q` (от 0 до 1), то ожидаемый выигрыш игрока в одном раунде:

`E(p, q) = 3(1 − p)(1 − q) + 5p(1 − q) + pq = 3 + 2p − 3q − pq`.

При фиксированном сопернике увеличение `p` повышает индивидуальное математическое ожидание: `dE/dp = 2 − q > 0`. Поэтому полное предательство (`P100`) — теоретически оптимальный индивидуальный выбор в заданной однократной игре. Это утверждение не переносится автоматически на игры с памятью, другими выплатами или критерием коллективного выигрыша.
